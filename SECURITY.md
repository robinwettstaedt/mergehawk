# Security Policy

## Reporting a Vulnerability

Please report security issues privately by email to `hello@mergehawk.dev`.
Do not open public GitHub issues for vulnerabilities.

Include:

- A short description of the issue
- Steps to reproduce or a proof of concept
- The affected MergeHawk version or commit
- Any relevant logs, screenshots, or crash reports

I will acknowledge valid reports as soon as practical and coordinate fixes
before public disclosure.

## Supported Versions

Until MergeHawk has a stable public release history, security fixes target the
latest GitHub release and the current `main` branch.
